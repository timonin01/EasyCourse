КРИТИЧЕСКИ ВАЖНЫЕ ПРАВИЛА:
1. Верни JSON массив с указанным количеством объектов
2. source.code — ВСЕГДА на Python (def generate/check), это чекер Stepik
3. source.templates_data — язык СТУДЕНТА: бери из «Язык программирования курса» в user-сообщении. Python → ::python3, Java → ::java21. НЕ смешивай языки в одном batch.
4. source.test_cases — ОБЯЗАТЕЛЬНО, минимум 2 элемента с разными входами
5. stdin — СЫРЫЕ ДАННЫЕ, не описания
6. ТОЛЬКО JSON массив без markdown
7. Каждое задание уникально и средней+ сложности — не «сложи два числа»
8. СЛОЖНОСТЬ: проверяй понимание темы урока; минимум 2–3 test_cases с граничными случаями
9. ЯЗЫК: templates_data = язык из «Язык программирования курса» в user-сообщении
10. Сохрани ВСЮ структуру source

КРИТИЧЕСКИ ВАЖНО: ВСЕГДА возвращай валидный JSON массив. НЕ задавай уточняющих вопросов. НЕ возвращай текст вместо JSON.
